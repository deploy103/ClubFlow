# ClubFlow

동아리 가입 요청, 관리자 승인, 동아리 배정, 역할별 운영 화면을 한 흐름으로 처리하는 클럽 관리 플랫폼입니다.

## 주요 기능

- 회원가입 후 승인 대기 상태로 자동 진입
- 관리자의 가입 요청 승인 / 반려
- 승인 시 동아리와 역할 직접 배정
- 멤버 / 리더 / 관리자 화면 분리
- 리더의 동아리 공지 등록
- 관리자의 동아리 추가와 사용자 현황 조회
- 세션 쿠키 인증과 CSRF 보호

## 화면 구성

- 공개 화면: 로그인, 회원가입
- 승인 대기 화면: 요청 상태와 안내 확인
- 멤버 화면: 내 동아리, 공지, 프로필
- 리더 화면: 멤버 관리, 공지 관리
- 관리자 화면: 대시보드, 가입 승인, 동아리 관리, 사용자 관리

최근 UI는 운영툴 느낌에 맞춰 다크 사이드바, 선명한 카드/표, 로그인 히어로 워크플로우 중심으로 정리했습니다.

## 프로젝트 구조

```text
apps/
  api/      Fastify + TypeScript API 서버
  web/      React + Vite 프론트엔드
packages/
  shared/   프론트엔드와 백엔드가 공유하는 타입
scripts/
  smoke-test.mjs
docs/
  architecture.md
  current-status.md
```

프론트엔드 화면은 `apps/web`, API와 도메인 로직은 `apps/api`, 공용 타입은 `packages/shared`에 있습니다.

## 실행

```bash
corepack pnpm install
corepack pnpm dev
```

- 웹: `http://localhost:5173/`
- API: `http://localhost:4000/`

`5173` 포트가 이미 사용 중이면 Vite가 다음 포트로 자동 전환합니다. `.env` 파일이 없어도 기본값으로 실행됩니다.

## 사용법

처음 확인할 때는 아래 순서대로 보면 됩니다.

### 1. 앱 켜기

터미널에서 프로젝트 폴더로 이동한 뒤 실행합니다.

```bash
corepack pnpm install
corepack pnpm dev
```

브라우저에서 `http://localhost:5173/` 을 엽니다. 만약 터미널에 `5174`, `5175`처럼 다른 포트가 나오면 그 주소로 들어가면 됩니다.

### 2. 바로 로그인해 보기

로그인 화면의 `테스트 계정` 버튼을 누르면 이메일과 비밀번호가 자동으로 채워집니다.

- 전체 관리는 `관리자`
- 동아리 운영은 `리더`
- 일반 사용자는 `멤버`

원하는 계정을 고른 뒤 `로그인` 버튼을 누르면 역할에 맞는 화면으로 이동합니다.

### 3. 새 가입 요청 보내기

1. 로그인 화면에서 `회원가입`을 누릅니다.
2. 이름, 학번, 이메일, 연락처, 비밀번호를 입력합니다.
3. 희망 동아리와 자기소개, 지원 메시지를 입력합니다.
4. `가입 요청 보내기`를 누릅니다.

가입 요청을 보내면 바로 승인 대기 화면으로 이동합니다. 이 상태에서는 멤버나 리더 화면에 들어갈 수 없습니다.

### 4. 관리자가 가입 승인하기

1. 관리자 계정으로 로그인합니다.
2. 왼쪽 메뉴에서 `가입 승인`을 누릅니다.
3. 대기 중인 요청을 확인합니다.
4. 배정할 동아리와 역할을 선택합니다.
5. `승인` 또는 `반려`를 누릅니다.

승인하면 사용자는 선택된 동아리와 역할을 받습니다. 반려하면 승인 대기 화면에서 상태를 확인할 수 있습니다.

### 5. 승인된 사용자 확인하기

승인된 사용자는 다시 로그인하거나 새로고침하면 역할에 맞는 화면으로 들어갑니다.

- `member`: 내 동아리, 공지, 내 정보 확인
- `leader`: 멤버 목록 확인, 동아리 공지 작성
- `admin`: 가입 승인, 동아리 추가, 사용자 현황 확인

### 6. 동아리 추가하기

관리자 계정으로 로그인한 뒤 `동아리` 메뉴에서 새 동아리를 추가할 수 있습니다.

입력할 내용:

- 동아리 이름
- 카테고리
- 소개
- 모집 메모

추가된 동아리는 가입 승인 화면에서 배정 대상으로 사용할 수 있습니다.

### 7. 공지 작성하기

리더 계정으로 로그인한 뒤 `공지 관리` 메뉴에서 동아리 공지를 작성할 수 있습니다.

- 제목과 내용을 입력합니다.
- 중요 공지는 `상단 고정 공지로 올리기`를 체크합니다.
- `공지 등록`을 누르면 멤버 화면에도 표시됩니다.

### 8. 자주 헷갈리는 점

- 서버를 껐다 켜면 데이터가 초기화됩니다. 현재는 인메모리 저장소를 사용합니다.
- 웹 포트가 `5173`이 아닐 수 있습니다. 터미널에 나온 Vite 주소를 확인하세요.
- API는 기본적으로 `http://localhost:4000/`에서 실행됩니다.
- 로그인이 이상하면 로그아웃 후 다시 로그인하거나 브라우저 새로고침을 해보면 됩니다.

## 검증

```bash
corepack pnpm typecheck
corepack pnpm build
corepack pnpm smoke
```

스모크 테스트는 다음 흐름을 확인합니다.

- 헬스체크
- 비인증 접근 차단
- 공개 동아리 목록 조회
- 회원가입과 승인 대기 조회
- 관리자 승인
- 승인 후 멤버 접근
- 리더 공지 작성
- 역할 기반 접근 제어
- CSRF 보호
- 로그아웃

## 참고

- 현재 저장소는 인메모리 데이터 저장소를 사용하므로 서버 재시작 시 데이터가 초기화됩니다.
- 실제 운영 배포 전에는 영속 저장소, 운영용 쿠키 시크릿, 배포 환경별 `WEB_ORIGIN` 설정이 필요합니다.
